# Cafe Riva website

A responsive, single-page restaurant website built with plain HTML, CSS, and JavaScript. No paid libraries or build step required.

## Preview

Open `index.html` in a browser. Internet access is used for the Google Fonts; the website and custom hero image are local files.

## Publish for free

Upload the contents of this folder to a static hosting service such as GitHub Pages, Netlify, or Cloudflare Pages. No backend or paid subscription is required for this static site.

## Before publishing

- Replace the sample dishes with Cafe Riva's confirmed menu and prices.
- Add the cafe address, opening hours, phone/WhatsApp booking link, and social profile.
- The current menu and restaurant copy is sample promotional content.
